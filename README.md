# Dear Wallet

iPhone-first money diary. Soft Y2K, no shame, reward-first.

Build instructions and design handover live in [`dear-wallet-handover/`](./dear-wallet-handover/README.md) until they are moved into the repo root (step 02).

## Stack

React Native · Expo (dev build, expo-router) · NativeWind · Supabase · TypeScript

## Bundle id

`com.pixelwitch.dearwallet`

## Run

```bash
npm install
npx expo run:ios
```
